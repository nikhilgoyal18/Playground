### CLAUDE.md Entropy — Every Month It Gets Longer and Worse `AI/ML`
- Mnimiy surfaces a structural problem with Claude Code's CLAUDE.md: one-off corrections accumulate into permanent rules, context ages out, contradictions go undetected, and nobody audits it
- The proposed solution is "Dreaming" — a tool that reads up to 100 past conversation logs and automatically audits/rewrites CLAUDE.md to reflect current intent rather than historical corrections
- This is a real failure mode: the configuration file that's supposed to improve Claude's output becomes the source of its degradation over weeks of use
- Implication: any system that accumulates human corrections without a reconciliation pass will drift; the "Dreaming" audit pattern is applicable beyond CLAUDE.md to any prompt/config system that grows organically (34 likes, 10 replies — strong resonance among Claude Code users)
